# Bejeweled LIVE

MonoGame port of the Windows Phone Bejeweled LIVE 1.0.3 decompilation.

## Build

Requires .NET 9. MonoGame packages and MGCB tools are pinned in the project files.

```powershell
dotnet tool restore
dotnet build BejeweledLIVE.Desktop/BejeweledLIVE.Desktop.csproj
dotnet run --project BejeweledLIVE.Desktop
```
